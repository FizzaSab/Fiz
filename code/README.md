# Data and prediction utilities

Small Python utilities for reading the experimental data and saved prediction exports included in this repository. They operate only on the actual CSV files and do not change the data or generate reaction outcomes.

Run from the repository root:

```bash
python code/inspect_data.py
python code/inspect_predictions.py
```

These scripts summarize stored data; they are not model-training or reverse-optimization implementations. The prediction and EFI methodology is described in the associated research manuscript and Supporting Information.
